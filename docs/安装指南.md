# TVLock 电视答题锁 · 安装指南

一个 APK 直接装在安卓智能电视上：孩子看电视每 30 分钟 / 1 小时 / 2 小时（可自定义）锁屏出一道题，遥控器答题，答错连答、答对不再出，断电续题，手机同一 WiFi 管理，题库随时换。

内置小学一年级题库 1766 题（口算 + 拼音），面板上传自己的 JSON 题库即可完全替换（不分学科，语数英混编都行）。

## 一、快速开始（三条命令）

```bash
./setup_env.sh            # 1. 搭建编译环境（仅首次，下载约 650MB）
./build.sh                # 2. 编译 APK + 跑单元测试
./install.sh 192.168.x.x  # 3. 安装到电视（换成电视的 IP）
```

装好后：手机和电视连同一个 WiFi，手机浏览器打开面板（见下节「手机怎么打开面板」）。

## 二、手机怎么打开面板

面板地址有两种写法：

| 地址 | 适用 |
|------|------|
| `http://tvlock.local:8080` | iPhone / iPad / Mac（原生支持 .local 域名） |
| `http://电视IP:8080`（如 `http://192.168.3.168:8080`） | **安卓手机（推荐）** / 电脑 |

**为什么安卓手机打不开 tvlock.local？** 这是安卓系统的普遍限制：安卓浏览器不用 mDNS 解析 `.local` 域名（查询被发给普通 DNS 服务器，必然解析失败），不是应用故障，也无法通过设置修复。安卓手机请直接用 IP 访问：

1. **查电视 IP**：电视 设置 → 网络 → 网络状态 / 本机信息（各品牌路径见下表）；应用首次打开的电视端状态页上也有 IP 大字和二维码
2. 手机浏览器打开 `http://电视IP:8080`
3. **一劳永逸的做法**（推荐）：给电视固定 IP（路由器管理页 → DHCP 设置 / 地址保留，把电视 IP 绑定到电视 MAC 地址），然后手机浏览器菜单里把面板「**添加到主屏幕**」，以后桌面点一下直达，无需记 IP

电视 IP 查看路径（常见品牌）：

| 品牌 | 路径 |
|------|------|
| 小米/Redmi | 设置 → 网络 → 网络状态 |
| 海信 | 设置 → 更多设置 → 网络 |
| TCL | 设置 → 网络 → 网络详情 |
| 创维 | 设置 → 网络设置 → IP 设置 |
| 华为/荣耀智慧屏 | 设置 → 网络 → 网络状态 |

## 三、电视端准备：开启网络调试（ADB）

不同品牌路径略有差异：

| 品牌 | 常见路径 |
|------|----------|
| 小米电视 | 设置 → 账号与安全 → ADB 调试（设为允许）。若无此选项：设置 → 关于 → 连续点「版本号」7 次开启开发者模式 |
| 海信 | 设置 → 更多设置 → 关于 → 连点「版本号」→ 返回找「开发者选项」→ USB/网络调试 |
| TCL | 设置 → 系统 → 关于 → 连点「版本号」→ 开发者选项 → ADB 调试 |
| 创维 | 设置 → 关于本机 → 连点「本机编号」→ 工厂菜单中开启 ADB |
| 华为/荣耀智慧屏 | 设置 → 关于 → 连点「产品版本号」→ 开发人员选项 → ADB 调试 |
| 当贝/天猫盒子 | 设置 → 关于 → 连点版本号 → 打开 USB 调试 |

然后电脑执行 `./install.sh <电视IP>`。电视上如弹出「允许 USB 调试」确认框，用遥控器选允许/确定。

> 备选安装方式（不使用 ADB）：把 `app/build/outputs/apk/debug/app-debug.apk` 拷到 U 盘，插电视，用电视自带的「文件管理/媒体中心」打开安装（需在设置里允许「安装未知来源应用」）。装好后打开应用一次；悬浮窗权限无法手动授予的极少数设备上，倒计时悬浮窗不显示但锁机功能不受影响。

## 四、安装后必做：允许开机自启动

为防止断电/重启后锁机状态丢失（状态本身永久保存，只是需要应用被拉起）：

| 品牌 | 路径 |
|------|------|
| 小米电视 | 设置 → 应用 → 应用管理 → 电视答题锁 → 权限管理 → 开机自启动 → 允许 |
| 海信 | 设置 → 应用管理 → 电视答题锁 → 自启动 |
| TCL | 设置 → 应用 → 电视答题锁 → 自启动 |
| 通用 | 若找不到该选项，可在「开发者选项」中确认应用未被省电策略限制 |

说明：即使忘记开启，断电后状态也完整保留（没答完的题、答错次数、输入进度、连答债都在），只是孩子开机后需家长手动打开一次应用即恢复锁屏。

## 五、日常使用

### 手机面板
- 一键锁机 / 解锁（暂停定时）/ 恢复定时
- 修改答题间隔（30 分钟 / 1 小时 / 2 小时 / 自定义 1~240 分钟）
- 实时查看：是否锁定、当前题目、剩余时间、答错次数、题库剩余
- 上传新题库（无感热更新，正在锁定的题不受影响）、导出当前题库
- 可开启 4 位面板管理码（防止孩子用手机自己解锁）

### 遥控器答题
- 选择题：方向键移动，OK 确认；**数字键 1~9 直接选第 N 个选项**
- 填空题：按数字键输入；屏幕键盘两行布局，删除/确定在键盘末尾，一屏可见无需翻页
- 答错不换题，一直答到对为止；一道题答错过，答对后需再连答一道新题才能回播放页（激励认真作答）
- 答对过的题永不再出；题库全部答完会从头轮回（锁屏和面板都有「剩余 N 题」提示）
- 答对时礼花特效 + 秒回播放页

### 电视端家长兜底
锁屏界面按遥控器 **上 上 下 下 左 右 左 右** → 输入管理码（默认 1234，手机面板可改）→ 解锁。

### 题库格式
```json
[
  {"q": "5+7等于几？", "ans": "12"},
  {"q": "9+6等于几？", "opts": ["12", "15", "18"], "ans": "2"},
  {"q": "cat 的中文意思是？", "opts": ["狗", "猫", "帽子", "杯子"], "ans": "猫"}
]
```
- 纯题目数组，**不分学科**，语文、数学、英语都放一起即可
- 带 `opts` = 选择题（`ans` 填 1 起始的选项序号，也可以直接填选项文本）
- 不带 `opts` = 填空题（`ans` 为答案文本，纯数字答案按数值比较，如 "012" 等于 "12"）
- 最少 1 题，最多 5000 题
- 旧版分类格式（按学科分组的对象）也能正常导入
- 上传坏文件会被自动拦截，主库不受影响

### 题库文件位置（电视上）
`/sdcard/TVLock/questions.json`（主库）、`/sdcard/TVLock/questions.json.bak`（换库前的自动备份）、`/sdcard/TVLock/inbox/`（U 盘投放新题库的目录）、`/sdcard/TVLock/inbox/rejected/`（被拦截的坏文件）。把 .json 文件放进 inbox 目录即自动导入（U 盘/文件管理器均可）。

## 六、验证防逃（建议装好依次测一遍）

1. 手机「一键锁机」→ 出题
2. 锁定时按遥控器 HOME 键 → 秒回锁屏
3. 拔电视电源 10 秒再插 → 同一道题、同样进度
4. 锁定时 `./install.sh <IP> --reboot` 重启 → 恢复锁屏
5. 锁定时上传新题库 → 当前题目不变、电视无任何提示
6. 传一个内容是乱码的 .json → 手机端显示拦截原因，题库完好

## 七、常见问题

**安卓手机打不开 tvlock.local？** 见第二节——安卓系统不解析 `.local` 域名，用 `http://电视IP:8080` 即可；固定 IP + 添加到主屏幕可一劳永逸。iPhone 的 Safari 原生支持，直接用 tvlock.local。

**首次锁机弹出「屏幕固定」确认框？** 家长用遥控器按一次「确定」即可（固定后 HOME 键完全失效）。即使按了取消，应用内置看门狗也能把锁屏拉回。

**应用后台一段时间被杀（反复退出/面板断连）？** 部分投影仪/电视（如小米激光投影仪等 JMGO 方案设备）内置后台清理守护（com.sparkle.hippo，约 2 分钟扫描一圈），会强杀后台应用并顺带清掉自愈闹钟。应用已内置多层防护：

1. **系统进程白名单伪装（核心）**：应用包名伪装为系统进程样式（com.android.* 开头），命中 hippo 豁免白名单，实测不再被强杀；
2. **倒计时悬浮窗常驻**：布防期间右上角常驻小倒计时，进程处于可见状态，进一步降低被后台清理的概率；
3. **静音循环播放**：清理工具通常豁免「正在播放音频」的应用（自动生效）；
4. **锁屏拉回智能退避**：间隔指数退避到 30 秒，不触发系统反滥用保护；
5. 仓库里另有独立看门狗 App（watchdog module）可双 App 互保，默认不安装；已装上的会继续双向互保，被一键清理后 3 秒内互相拉回；
6. 极端情况（如源切换时系统级连杀）被杀也没关系：重新打开应用或重启设备会自动恢复全部锁定状态（断电续题设计）。

**想彻底换成自己的题库？** 面板导出当前题库 → 手机/电脑上改 → 上传（或放进电视的 TVLock/inbox 目录）。生成脚本 `tools/gen_bank.py` 可重新生成初始题库。

**升级新版本？** 重新 `./build.sh && ./install.sh <电视IP>`，覆盖安装自动保留全部状态（间隔、管理码、答题进度、已答记录）。

**卸载？** `./install.sh --uninstall <电视IP>`，或电视设置里正常卸载（若额外装过看门狗 App，一并卸载）。卸载不会留下任何数据。
