# TVLock 电视答题锁 · 安装指南

一个 APK 直接装在国产安卓智能电视上：看电视定时锁机出题（一年级口算+拼音），遥控器答题，断电续题，手机同一 WiFi 免记 IP 管理，题库无感热更新。

## 一、快速开始（三条命令）

```bash
./setup_env.sh          # 1. 搭建编译环境（仅首次，下载约 650MB）
./build.sh              # 2. 编译 APK + 跑单元测试
./install.sh 192.168.x.x  # 3. 安装到电视（换成电视的 IP）
```

装好后：手机和电视连同一个 WiFi，手机浏览器打开 **http://tvlock.local:8080**（或扫电视屏幕上的二维码，或输入 http://电视IP:8080）。

## 二、电视端准备：开启网络调试（ADB）

不同品牌路径略有差异：

| 品牌 | 常见路径 |
|------|----------|
| 小米电视 | 设置 → 账号与安全 → ADB 调试（设为允许）。若无此选项：设置 → 关于 → 连续点「版本号」7 次开启开发者模式 |
| 海信 | 设置 → 更多设置 → 关于 → 连点「版本号」→ 返回找「开发者选项」→ USB/网络调试 |
| TCL | 设置 → 系统 → 关于 → 连点「版本号」→ 开发者选项 → ADB 调试 |
| 创维 | 设置 → 关于本机 → 连点「本机编号」→ 工厂菜单中开启 ADB |
| 华为/荣耀智慧屏 | 设置 → 关于 → 连点「产品版本号」→ 开发人员选项 → ADB 调试 |
| 当贝/天猫盒子 | 设置 → 关于 → 连点版本号 → 打开 USB 调试 |

电视 IP 查看路径：设置 → 网络 → 网络状态/本机信息。

然后电脑执行 `./install.sh <电视IP>`。电视上如弹出「允许 USB 调试」确认框，用遥控器选允许/确定。

> 备选安装方式（不使用 ADB）：把 `app/build/outputs/apk/debug/app-debug.apk` 拷到 U 盘，插电视，用电视自带的「文件管理/媒体中心」打开 APK 安装（需在设置里允许「安装未知来源应用」）。装好后打开应用一次，再手动执行不了授权命令的话，看门狗在多数电视上仍然生效。

## 三、安装后必做：允许开机自启动

为防止断电/重启后锁机状态丢失（状态本身永久保存，只是需要应用被拉起）：

| 品牌 | 路径 |
|------|------|
| 小米电视 | 设置 → 应用 → 应用管理 → 电视答题锁 → 权限管理 → 开机自启动 → 允许 |
| 海信 | 设置 → 应用管理 → 电视答题锁 → 自启动 |
| TCL | 设置 → 应用 → 电视答题锁 → 自启动 |
| 通用 | 若找不到该选项，可在「开发者选项」中确认应用未被省电策略限制 |

说明：即使忘记开启，断电后状态也完整保留（没答完的题、答错次数、输入进度都在），只是孩子开机后需家长手动打开一次应用即恢复锁屏。

## 四、日常使用

### 手机面板（http://tvlock.local:8080）
- 一键锁机 / 解锁（暂停定时）
- 修改答题间隔（5/10/15/20/自定义分钟）
- 实时查看：是否锁定、当前题目、剩余时间、答错次数
- 上传新题库（无感热更新，正在锁定的题不受影响）、导出当前题库
- 可开启 4 位面板管理码（防止孩子自己解锁）

### 遥控器答题
- 选择题：方向键移动，OK 确认；**数字键 1~9 直接选第 N 个选项**
- 填空题：按数字键输入，屏幕键盘有删除/确定
- 答错不换题，一直答到对为止

### 电视端家长兜底
锁屏界面按遥控器 **上 上 下 下 左 右 左 右** → 输入管理码（默认 1234，手机面板可改）→ 解锁。

### 题库格式
```json
{
  "math": [
    {"q":"5+7等于几？","ans":"12"},
    {"q":"9+6等于几？","opts":["12","15","18"],"ans":"2"}
  ],
  "pinyin": [
    {"q":"山是第几声？","opts":["一声","二声","三声","四声"],"ans":"3"}
  ]
}
```
- 带 `opts` = 选择题（`ans` 填 1 起始的选项序号，也可以直接填选项文本）
- 不带 `opts` = 填空题（`ans` 为答案文本）
- 分类名随意（math/pinyin/english 都行）
- 上传坏文件会被自动拦截，主库不受影响

### 题库文件位置（电视上）
`/sdcard/TVLock/questions.json`（主库）、`/sdcard/TVLock/inbox/`（U 盘投放新题库的目录）、`/sdcard/TVLock/inbox/rejected/`（被拦截的坏文件）。

## 五、验证防逃（建议装好依次测一遍）

1. 手机「一键锁机」→ 出题
2. 锁定时按遥控器 HOME 键 → 1 秒内回到锁屏
3. 拔电视电源 10 秒再插 → 同一道题、同样进度
4. 锁定时 `./install.sh <IP> --reboot` 重启 → 恢复锁屏
5. 锁定时上传新题库 → 当前题目不变、电视无任何提示
6. 传一个内容是乱码的 .json → 手机端显示拦截原因，题库完好

## 六、常见问题

**手机打不开 tvlock.local？** 部分老手机系统不解析 .local 域名。用电视屏幕显示的 IP 地址（http://电视IP:8080）或直接扫二维码。

**首次锁机弹出「屏幕固定」确认框？** 家长用遥控器按一次「确定」即可（固定后 HOME 键完全失效）。即使按了取消，看门狗也能在 1 秒内把锁屏拉回。

**想彻底换成自己的题库？** 面板导出当前题库 → 手机/电脑上改 → 上传。生成脚本 `tools/gen_bank.py` 可重新生成初始题库。

**卸载？** `./install.sh --uninstall <电视IP>`，或电视设置里正常卸载。卸载不会留下任何数据。
