# TVLock 电视答题锁

直接安装在国产安卓智能电视上的「看电视定时答题锁」：孩子每看 N 分钟电视出一道一年级口算/拼音题，答对才能继续；断电、重启、拔插头都逃不掉；手机同 WiFi 免记 IP 一键管理。

纯本地运行，不联网、不依赖任何外部硬件或服务。

## 功能

- 定时锁机出题（5/10/15/20/自定义分钟），遥控器数字键/方向键答题
- 填空题 + 选择题自动识别
- 断电续题：题目、答错次数、已输入内容全部持久化，重启原样恢复
- `http://tvlock.local:8080` 免记 IP（mDNS 局域网域名 + 电视屏二维码/IP 大字兜底）
- 手机面板：一键锁机、一键解锁、改间隔、实时看题、上传题库、导出题库、可选管理码
- 题库无感热更新：正在锁定的题绝不变化；坏文件自动拦截不崩系统
- 内置一年级题库 1766 题（口算 1211 + 拼音 555，`tools/gen_bank.py` 可再生成）
- 防逃：屏幕固定 + 看门狗秒级拉回 + 墙钟倒计时（断电期间时间照算）+ 时钟回拨检测

## 快速开始

```bash
./setup_env.sh            # 仅首次：搭建编译环境（项目内 .env/，不动系统）
./build.sh                # 编译 APK + 单元测试
./install.sh <电视IP>      # ADB 安装到电视（电视端先开网络调试）
```

手机与电视同一 WiFi → 打开 http://tvlock.local:8080

详细步骤与各品牌电视的调试/自启动开启路径见 [docs/安装指南.md](docs/安装指南.md)。

## 项目结构

```
app/                     Android 工程（Kotlin，minSdk 21 / targetSdk 29）
  src/main/java/com/tvlock/app/
    AppCore.kt           核心调度中枢（500ms 心跳：到点锁机/看门狗/回拨检测）
    LockActivity.kt      全屏答题锁屏（遥控器适配 + 屏幕固定 + 管理码兜底）
    SetupActivity.kt     电视端状态页（tvlock.local 大字 + IP + 二维码）
    BootReceiver.kt      开机自启
    service/             前台服务 + NanoHTTPD 手机面板服务器
    data/                state.json 原子读写 / 题库校验与热更新
    core/Scheduler.kt    锁机判定纯函数（单元测试覆盖）
    net/                 mDNS 应答器（tvlock.local）+ DNS 编解码
  src/main/assets/       panel.html（手机面板）+ questions.json（初始题库）
tools/gen_bank.py        题库生成器（数学 + 拼音，可自定义再生成）
tools/gen_icons.py       图标生成器
setup_env.sh / build.sh / install.sh
```

## 题库格式

```json
{
  "math": [
    {"q":"5+7等于几？","ans":"12"},
    {"q":"9+6等于几？","opts":["12","15","18"],"ans":"2"}
  ],
  "pinyin": [
    {"q":"山是第几声？","opts":["一声","二声","三声","四声"],"ans":"3"}
  ]
}
```

带 `opts` 是选择题（`ans` 为 1 起始序号），不带是填空题。上传后自动校验热更新，当前锁定的题不受影响。

## 防逃设计一览

| 逃逸手段 | 结果 |
|----------|------|
| 按 HOME / 返回 / 菜单 | 屏幕固定吃掉；兜底看门狗 1 秒内拉回 |
| 断电 / 拔插头 / 停电 | 墙钟倒计时照算，通电即恢复锁定 + 原题原进度 |
| 重启电视 | 开机广播恢复锁定 |
| 答错 | 不换题，一直答到对 |
| 改系统时间 | 时钟回拨超 60 秒直接锁机 |
| 更新题库想换掉难题 | 当前题独立存于 state.json，换库无效 |
| 用手机自己解锁 | 面板可开 4 位管理码 |
