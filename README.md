# TVLock 电视答题锁

直接安装在安卓智能电视上的「看电视定时答题锁」：孩子每看一段时间电视就出一道题，答对才能继续；断电、重启、拔插头都逃不掉；手机连同一 WiFi 即可管理。

纯本地运行，不联网、不依赖任何外部硬件或服务。内置小学一年级题库 1766 题（口算 + 拼音），随时可换成自己的题库。

## 功能

- **定时锁机出题**：间隔可选 30 分钟 / 1 小时 / 2 小时，或自定义 1~240 分钟；右上角常驻小倒计时（完全穿透不挡操作），到点全屏出题
- **遥控器答题**：选择题方向键移动 + 数字键直选；填空题数字键盘两行布局，一屏可见无需翻页
- **答错连答**：答错不换题一直答到对，答对后需再连答一道新题才能回播放页（激励认真作答）
- **答对不再出**：答对过的题永不再出，题库答完从头轮回；锁屏和面板都显示「剩余 N 题」
- **答对礼花特效** + 秒回播放页
- **断电续题**：题目、答错次数、已输入内容、连答债全部持久化，重启原样恢复
- **手机面板**（`http://tvlock.local:8080` 或电视 IP）：一键锁机、解锁、改间隔、实时看题、上传/导出题库、4 位管理码防孩子自解锁
- **题库无感热更新**：正在锁定的题绝不变化；坏文件自动拦截不进主库
- **题库格式极简**：纯题目数组，不分学科，语文数学英语放一起即可
- **防逃**：无障碍守卫 0ms 拦截 HOME 键（安装后遥控器开一次，见安装指南）+ 返回/菜单键直接吞掉 + 墙钟倒计时（断电期间时间照算）+ 时钟回拨检测；极端情况被系统强杀，重新打开应用即恢复全部锁定状态

## 快速开始

```bash
./setup_env.sh            # 仅首次：搭建编译环境（项目内 .env/，不动系统）
./build.sh                # 编译 APK + 单元测试
./install.sh <电视IP>      # ADB 安装到电视（电视端先开网络调试，见安装指南）
```

装好后手机与电视同一 WiFi，浏览器打开 **http://tvlock.local:8080**。

> 安卓手机普遍打不开 `.local` 域名（系统不支持 mDNS 解析），请用电视 IP 访问 `http://电视IP:8080`，详见 [docs/安装指南.md](docs/安装指南.md) 常见问题。

发布：推送 `v*` 标签触发 GitHub Actions，自动构建并发布单 APK Release。


## 题库格式

```json
[
  {"q": "5+7等于几？", "ans": "12"},
  {"q": "9+6等于几？", "opts": ["12", "15", "18"], "ans": "2"},
  {"q": "cat 的中文意思是？", "opts": ["狗", "猫", "帽子", "杯子"], "ans": "猫"}
]
```

- 纯题目数组，**不分学科**，各科题目放一起即可
- 带 `opts` 是选择题（`ans` 为 1 起始选项序号，或直接写选项文本）
- 不带 `opts` 是填空题（`ans` 为答案文本，纯数字按数值比较）
- 最少 1 题，最多 5000 题
- 旧版分类格式（按学科分组的对象）仍可正常导入

上传后自动校验热更新，当前锁定的题不受影响。

## 防逃设计一览

| 逃逸手段 | 结果 |
|----------|------|
| 按 HOME 键 | 部分设备还不完全确定 |
| 按返回 / 菜单 | 锁屏直接吞掉，无效 |
| 断电 / 拔插头 / 停电 | 墙钟倒计时照算，通电即恢复锁定 + 原题原进度 |
| 重启电视 | 开机广播恢复锁定 |
| 答错 | 不换题一直答到对，答对后还要连答一道新题 |
| 改系统时间 | 时钟回拨超 60 秒直接锁机 |
| 更新题库想换掉难题 | 当前题独立存于 state.json，换库无效 |
| 用手机自己解锁 | 面板可开 4 位管理码 |
